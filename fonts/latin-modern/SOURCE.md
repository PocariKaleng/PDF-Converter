# Latin Modern Roman 10

These four unmodified OpenType files in v1.106/ are a subset of the Latin Modern package:

- lmroman10-regular.otf
- lmroman10-bold.otf
- lmroman10-italic.otf
- lmroman10-bolditalic.otf

Upstream: https://www.gust.org.pl/projects/e-foundry/latin-modern/

Distribution: https://ftp.math.utah.edu/pub/tex/historic/fonts/latin-modern/lm-1.106/lm1.106otf.zip

All four font files report Version 1.106 in their name tables and CFF programs.
The original upstream
README and GUST Font License are preserved alongside the font files. Other
optical sizes and families from the upstream distribution are not included.
